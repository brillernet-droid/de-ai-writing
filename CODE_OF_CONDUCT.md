# Code Of Conduct

This project is for practical, source-safe writing improvement.

Participants should:

- critique text and methods, not people;
- avoid harassment, insults, or discriminatory language;
- avoid posting private drafts, personal data, or credentials;
- avoid using the project to fabricate citations, authorship, evidence, or credentials;
- respect that formal, second-language, technical, and academic writing can be legitimate without sounding casual.

Maintainers may remove comments, issues, or pull requests that violate these rules.
