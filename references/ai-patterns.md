# AI-Like Writing Signals

Use this as a warning list, not a ban list. Revise only when a phrase is vague, repeated, unsupported, or mismatched to the genre. Never introduce fake anecdotes, citations, mistakes, or quirks merely to sound human.

## High-Signal English Phrases

| Signal | Better move |
| --- | --- |
| `delve into`, `realm of`, `tapestry`, `in today's world` | Name the exact action, field, date, or context. |
| `pivotal`, `transformative`, `groundbreaking`, `revolutionary` | State what changed and why it matters. |
| `plays a crucial role`, `underscores the importance of`, `sheds light on` | State the mechanism, implication, or finding directly. |
| `seamless`, `robust`, `holistic`, `cutting-edge`, `actionable insights` | Name the actual property, component, or decision. |
| `unlock`, `empower`, `elevate`, `leverage`, `navigate` | Use a concrete verb: enable, use, reduce, compare, choose, or explain. |
| `it is important/worth noting`, `at its core`, `needless to say` | Delete the preface and start with the point. |
| `not merely`, `this is not just`, repeated `not only … but also …` | Keep the contrast only when it changes the argument; otherwise split it. |
| `in conclusion`, `moving forward`, `opens new avenues`, `paves the way` | End with the consequence, next decision, or open question. |
| vague authorities such as `experts argue`, `studies show` | Name and cite the source, or narrow/remove the claim. |

## High-Signal Chinese Phrases

| Signal | Better move |
| --- | --- |
| `需要说明的是`, `值得注意的是`, `当然`, `综上所述` | Delete the preface; write the claim, result, or conclusion. |
| `赋能`, `助力`, `打造`, `抓手`, `底层逻辑` | Name the actor, action, mechanism, and outcome. |
| `多维度`, `全方位`, `深度融合`, `高质量发展` | List the real dimensions, scope, or indicator. |
| `重要意义`, `尤为重要`, `不可或缺` | Explain the consequence or dependency. |
| `提供新的思路/路径`, `未来可期` | State the new method, next step, or remaining uncertainty. |
| repeated `不仅…而且…`, `首先…其次…最后…` | Keep only real logical relationships; split template-like sentences. |
| `随着 X 不断发展 … 未来可期` | Start with the concrete problem, actor, data point, or decision. |

## Structural Signals

- Generic opener: `In an era where …`, `As X continues to evolve …`, or `随着 X 不断发展 …`.
- Essay template: broad background → importance claim → abstract benefits → optimistic future.
- Paragraphs that all perform claim → elaboration → broad implication.
- Repeated triads, perfectly balanced contrasts, or synonym cycling around one stable term.
- Transition ladders: `Moreover`, `Furthermore`, `Additionally`, `Ultimately`; or `首先`, `其次`, `此外`, `最后`.
- Conclusions that praise the topic instead of stating a consequence, decision, limit, or unresolved question.
- A polished, equally weighted paragraph rhythm that ignores evidence and emphasis.

## Better Structures

- Claim → reason/evidence → implication.
- Evidence/case → interpretation → bounded conclusion.
- Problem → real constraint → chosen response.
- Finding → limitation → what can safely follow.
- Objection → answer → narrowed claim.
- Chronology, only when the sequence explains development or causality.

## Formatting And Chatbot Residue

- Delete assistant openers and sign-offs such as `Of course`, `Great question`, `当然可以`, `希望这对你有帮助`, and `Let me know if …` unless they belong in an actual email.
- Remove excessive bold-label bullets, generic headings (`Overview`, `Key points`, `Takeaways`), decorative emoji, needless horizontal rules, and tables used where two sentences would be clearer.
- Verify dates, studies, authorities, quotations, and citations. Plausible but unsourced specifics are more damaging than plain uncertainty.
- Keep formatting that serves the reader or is required by the target venue.

## Translation And Authorship Signals

- A translated sentence retains every source-language noun phrase but loses a clear main verb in the target language.
- Chinese prose uses English-style subject chains, repeated `其`, or passive constructions when a direct verb would be clearer.
- English prose repeats abstract nouns such as `development`, `importance`, `significance`, and `improvement` without an actor or mechanism.
- A paragraph sounds personal only because it adds a generic claim such as `I have always been passionate about …`; ask for a real detail or omit it.
- A draft uses `experts`, `research`, `reports`, or an exact statistic without an attributable source.

Better move: preserve the supplied fact, source, or personal detail; otherwise write a narrower sentence, flag the gap, or leave a placeholder for the author to complete.
