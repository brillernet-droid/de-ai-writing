# AI-Ish Lexicon

Treat this as a warning system, not a ban list. Revise an item when it is vague, repeated, unsupported, or unnatural for the genre. Preserve required terminology and use concrete alternatives only when they retain the meaning.

## English

| Pattern | Severity | Better move |
| --- | --- | --- |
| `delve into`, `deep dive`, `realm of`, `tapestry` | high | Name the action, subject, or domain. |
| `in today's world`, `fast-paced world`, `ever-evolving` | high | Start with the actual date, change, event, or problem. |
| `landscape`, `complex interplay`, `multifaceted`, `nuanced` | medium | Name the setting, variables, facets, or distinction. |
| `pivotal`, `transformative`, `groundbreaking`, `revolutionary` | high | State what changed and why it matters. |
| `plays a crucial role`, `is essential for`, `underscores the importance of` | high | State the actor, mechanism, and consequence. |
| `sheds light on`, `provides valuable insights`, `opens new avenues` | high | State the finding, decision, or next research question. |
| `growing body of literature`, `garnered increasing attention` | medium | Name the literature, source, or reason for attention. |
| `cutting-edge`, `state-of-the-art`, `innovative`, `robust` | medium | Name the benchmark, validation, novelty, or actual property. |
| `holistic`, `seamless`, `intuitive`, `user-friendly` | high | Name the dimensions, removed friction, or user task. |
| `unlock`, `empower`, `elevate`, `leverage`, `harness` | medium | Use a concrete verb such as use, enable, reduce, compare, or apply. |
| `synergy`, `ecosystem`, `catalyze`, `optimize` | medium | Explain the interacting actors, mechanism, or objective. |
| `at its core`, `it is important/worth noting`, `needless to say` | high | Delete the preface and state the point. |
| `in conclusion`, `moving forward`, `ultimately` | medium | End with the consequence, decision, or unresolved question. |
| repeated `moreover`, `furthermore`, `additionally` | low | Keep only transitions that express a real relation. |
| `not merely`, `this is not just`, repeated `not only … but also …` | high | Keep the contrast only when it changes the argument. |
| `from X to Y`, `whether you're A or B` | medium | Name the actual scope, audience, or use case. |
| `meticulously`, `thoughtfully`, `curated` | medium | Show the choice, care, or selection rather than praising it. |
| `plethora`, `myriad`, `treasure trove`, `beacon of` | high | Use a precise count or concrete description. |
| `actionable insights`, `data-driven`, `best practices` | medium | Name the decision, data, or practice. |
| `due to the fact that`, `in order to`, `a wide range of` | low | Prefer because, to, or the real range. |

## Chinese

| Pattern | Severity | Better move |
| --- | --- | --- |
| `需要说明的是`, `值得注意的是`, `当然` | high | Delete the preface and write the point. |
| `赋能`, `助力`, `打造`, `抓手`, `底层逻辑` | medium | Name who does what, through which mechanism, and with what result. |
| `闭环`, `深度融合`, `多维度`, `全方位` | medium | Describe the process, participating parts, or listed dimensions. |
| `高质量发展`, `降本增效`, `提质增效` | medium | Name the outcome and its measurable criterion. |
| `重要意义`, `尤为重要`, `不可或缺` | medium | Explain the consequence or dependency. |
| `未来可期`, `提供新的思路/路径` | high | State the next step, method, or unresolved question. |
| `综上所述`, `总而言之` | medium | End with the actual result, limit, or decision. |
| `不仅…而且…` as a repeated engine | high | Split the claims or keep the stronger one. |
| `首先…其次…此外…最后` in short prose | medium | Retain only real sequence, causal, or contrast links. |
| `随着 X 不断发展 … 重要意义 … 未来可期` | high | Start with a concrete actor, evidence, friction, or event. |

## Attribution And Uncertainty

| Pattern | Severity | Better move |
| --- | --- | --- |
| `experts argue`, `observers note`, `industry reports suggest` | high | Name and cite the source, or remove the borrowed authority. |
| `studies show`, `research suggests` without a source | medium | Supply a source or narrow the sentence to the available evidence. |
| `based on available information`, then speculation | high | State what is known and leave the gap visible. |
| stacked `may`, `might`, `could`, `potentially` | medium | Name the real source of uncertainty or keep one justified qualifier. |

## Replacement Principles

- Prefer precise nouns and verbs over importance adjectives.
- Repeat the correct technical term rather than rotating conspicuous synonyms.
- Replace generic praise with evidence, mechanism, scope, or consequence.
- Do not remove a term merely because it appears on this list; context controls the edit.
