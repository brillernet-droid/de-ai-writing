# AI-Ish Structure Patterns

Diagnose the shape of the writing, not just its vocabulary. The goal is not messier prose; it is an argument shape that fits the actual material.

## High-Signal Patterns

| Pattern | Severity | Better structural move |
| --- | --- | --- |
| Era opener → importance claim → broad benefits → future promise | high | Start with the actual claim, case, finding, constraint, or conflict. |
| `In an era where …` / `As X continues to evolve …` | high | Name the concrete change, actor, date, or decision. |
| Definition → importance → applications → future | medium | Choose the real purpose: explain, argue, compare, critique, or report. |
| Problem → solution → generic benefits → call to embrace | high | Show the trade-off, evidence, implementation detail, or decision. |
| Background → gap → solution → transformative impact | medium | Make the gap testable and the impact bounded. |
| Every paragraph: claim → elaboration → broad implication | high | Vary jobs: evidence, counterpoint, mechanism, limit, or consequence. |
| Three abstract benefits in every list | high | Keep only the points the material supports. |
| Transition ladder: `moreover` → `furthermore` → `additionally` | medium | Use causal, temporal, or contrastive relations only when needed. |
| Final paragraph says the topic is important and future-looking | high | End with a consequence, decision, limitation, or open question. |
| Perfectly even paragraph length or rhythm | medium | Let emphasis and evidence determine length. |
| Universal audience framing | high | Name the actual reader, field, stakeholder, or population. |
| Topic praise before topic explanation | high | Explain first; let importance emerge from evidence. |
| Generic summary of both sides without a stance | medium | State the claim, then acknowledge the exact boundary. |
| `not only X but also Y` or `this is not just X` repeated | high | Split the claims or state the meaningful contrast once. |
| Rule-of-three as the default for every idea | medium | Keep the number of points that the evidence warrants. |
| Elegant synonym cycling around one term | medium | Repeat the stable term when it is the clearest anchor. |
| Faux punchline fragments or aphorisms | medium | State the actual observation in a normal sentence. |
| `随着 X 不断发展 → 重要意义 → 未来可期` | high | Start with a specific problem, object, data point, or conflict. |

## Sentence-Level Signals

- `By doing X, we can Y` repeated as every recommendation.
- `X serves as a bridge between A and B` when the mechanism is unstated.
- `At its core, X is about Y` as a shortcut to a generic definition.
- `The future of X lies in Y` without a real forecast argument.
- `X is more than a tool; it is a catalyst for Y` as promotional upgrade language.
- `This finding highlights/underscores/reflects …` when a concrete subject could make the claim.
- Repeated `While X, Y` concessions or rhetorical questions answered immediately.

## Replacement Structures

- **Claim → evidence → implication**: state the point, show why, then state what follows.
- **Evidence → interpretation → bounded conclusion**: begin with a result, case, or quotation.
- **Problem → constraint → choice**: show the real limitation before the chosen response.
- **Finding → limitation → meaning**: useful for academic discussion sections.
- **Objection → answer → narrowed claim**: use when an objection genuinely matters.
- **Chronology**: use only when sequence explains development or causality.
- **Compare by criteria**: compare options using named criteria rather than generic pros and cons.
- **Friction → frame**: open with a failure, surprise, decision, or practical constraint.

## Revision Checklist

1. Write one line describing what each paragraph does.
2. Delete or merge paragraphs that only announce importance, modernity, complexity, or promise.
3. Move the strongest concrete detail earlier.
4. Replace generic transitions with an actual relation: cause, example, concession, contrast, or consequence.
5. Preserve necessary academic or technical structure, including conventional passive voice in Methods.
6. Let the ending remain open when an unresolved question is more accurate than an optimistic wrap-up.
